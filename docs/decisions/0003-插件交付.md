# 0003 插件只内部开发、单独交付；平台不点名任何插件
日期：2026-11-23　状态：有效

## 决定
- 设备插件**只由内部开发**：不做对外的插件开发包，设备包不做签名。
- 每种设备一个 `.sagedev` 设备包，单独交付；SAGE 安装包里**不带任何设备**，包括通用串口/网口链路 `comm_link`。
- 平台里原来给 `comm_link` 做的专用设置界面**删除**（用户 2026-11-23 决定）。现在 `comm_link` 的设置在设备编辑的"高级设置"里以 JSON 编辑。
- 12 个板卡插件（研华 PCI-1710L/1762/6208V、MOXA CP-118U-I、阿尔泰 PXI2355L/2604、JCXD 四款、LVDT、电容板）从旧分支恢复，放进 `plugin/`。

## 原因
- 插件作者只有内部人员，签名和对外文档是额外负担，需要时再加。
- 平台点名某个插件，就和那个插件绑在一起，违背 0002 的依赖方向。

## 怎么执行
- 以后若要让插件有友好的设置界面：在 SDK 里让插件**声明**设置项（pydantic 模型 → JSON Schema），平台用已有的通用表单组件（`features/manual/schema-fields.tsx`，设备工具参数表单就是它画的）自动生成。不要再为单个插件写专用界面。
- 改动见提交 `b7dc1fe`（恢复插件）、`0778ed2`（删除专用界面）。
