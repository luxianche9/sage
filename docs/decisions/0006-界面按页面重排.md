# 0006 界面按页面重排：六页、每页最多两栏
日期：2026-11-24　状态：有效

## 决定
- **左侧图标栏是页面导航**，一个图标一整页。项目内六页，按"搭台架 → 编流程 → 运行 → 回看"排：

  | 页 | 左栏 | 中间 |
  |---|---|---|
  | 设备 | 设备、被测件 / 夹具列表 | 选中那台的详情：信息和状态、端口针脚、信号和当前值、手动操作、自检 |
  | 接线 | 硬件列表（拖到画布）；第二个页签是变更记录 | 画布或针脚表，一个开关切换；选中连线的针脚显示在画布下方 |
  | 协议 | 协议（ICD）文件列表 | 协议编辑器；顶上一栏管"解析哪些数据流" |
  | 流程 | 步骤卡片 | 测试流程，步骤属性就地展开；校验问题列在底部 |
  | 运行 | 步骤进度、功能组勾选、运行按钮；编辑布局时换成组件库和控件属性 | 运行头、上位机画布、时间轴 |
  | 记录 | 历次运行；选中一条后换成这次的步骤 | 这次运行的只读回放（同一块画布） |

- **每页最多两栏（左栏 + 中间）**，右边留给 AI 助手。不要右侧属性栏：属性就地展开、放左栏，或放在中间区域的底部。
- **要编辑的东西不进弹窗**。弹窗只留给必须打断人的确认（人工判定、恢复确认、AI 高风险操作、保存修改、删除）和几项就填完的短表单（添加设备、运行参数、预设命名、新建接线、编辑针脚）。
- **点列表项只改本页**；换页只发生在点左侧图标，或点写明去向的按钮（"去协议页""编辑流程"）。
- **一页最多一个视图开关**。接线页保留"画布 / 表格"这一个（用户 2026-11-24 定）。
- 运行页只显示实时数据和当前（或刚结束的）这次运行；历史回放在记录页，用它自己的一块只读画布。
- "全部回到安全状态"放在标题栏，在哪一页都按得到。
- 再点一次当前页的图标，收起或展开左栏。

## 原因
- 重排前整个软件只有"测试台架"一页：左侧图标只换侧栏，中间另有一个开关（运行监控 / 工位接线），两边互不相干。流程编辑和协议编辑没地方放，只好进弹窗；运行历史在侧栏，点一条只能把中间换成回放，用户感觉"跳走"；运行时看不看得到步骤，取决于侧栏当时选了什么。
- 用户要求最多两栏：右边要放 AI 助手，三栏放不下。
- 0005 里用户否决的仍然有效：画布是单页，不弹独立窗口。

## 怎么执行
- 页面在 `app/apps/desktop/src/renderer/features/` 各自的目录里，统一用 `ui` 里的 `PageFrame`（左栏 + 分隔条 + 中间）。页面的名字、顺序、跨页跳转在 `lib/pages.ts`。
- 六页都保持挂载，换页只是隐藏：流程草稿、实时数据、画布视野不丢。
- 新加功能先问"它属于哪一页的左栏还是中间"；需要第三栏时，改成就地展开或放底部。
- 画布上的控件和它们的属性表单仍在重做（见 0005）；重做时组件库和属性都落在运行页"编辑布局"时的左栏。
