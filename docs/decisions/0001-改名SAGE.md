# 0001 产品改名 SAGE
日期：2026-11-23　状态：有效

## 决定
产品从 testStand 改名为 SAGE（赛捷）。一次改干净，**不保留旧名兼容**：

| 旧 | 新 |
|---|---|
| 程序名 testStand、程序标识 `com.teststand.desktop` | SAGE、`com.sage.desktop` |
| 用户数据目录 `%APPDATA%\testStand` | `%APPDATA%\SAGE` |
| Python 包 `teststand_backend` / `teststand_device_sdk` / `teststand_adapter_<名>` | `sage_backend` / `sage_device_sdk` / `sage_plugin_<名>` |
| 插件入口点组 `teststand.devices`、配置段 `[tool.teststand.package]` | `sage.devices`、`[tool.sage.package]` |
| 设备包 `.tsdev`、硬件定义 `.tshw`、工程标记 `.teststand` | `.sagedev`、`.sagehw`、`.sage` |
| 前端 `@teststand/*`、`window.teststand`；环境变量 `TESTSTAND_*` | `@sage/*`、`window.sage`；`SAGE_*` |

## 原因
- testStand 与 NI TestStand 撞名。
- 还没有交付过任何客户，没有旧数据、旧设备包要兼容；插件一旦交出去再改这些约定，已交付的设备包都会失效，所以趁现在一次改完。

## 怎么执行
- 提交 `40d7a03`。`pnpm check:branding` 禁止旧名和旧扩展名出现在代码和文档里（`CHANGELOG.md` 和本目录除外）。
- 不要建顶层 Python 包或命令叫 `sage`：数学软件 SageMath 占用了这个名字。带前缀（`sage_backend`）没问题。
- 商标：英国 Sage 集团是大型财务软件公司，商用前要查商标（未做）。
- 开发机上旧的 `%APPDATA%\testStand` 数据不会自动搬过来，需要的话手动复制。
